What happens each 24h run

Query agent-created rules rules table
Fetches all rows where created_by = 'agent' and active = true. These are skills the relay wrote itself — never touches bundled or manually-created rules.
Detect stale skills low use
Checks age and use_count. Skills unused for 14+ days with fewer than 2 uses are flagged as review candidates and logged.
Auto-archive dead skills 0 uses · 60+ days
Skills with use_count = 0 and age > 60 days are set to active = false with a curator_note explaining why. Never deleted — always recoverable.
Query insights insights table
Runs same analysis on the insights table — accumulated knowledge from observations across sessions.
Archive stale insights 0 uses · 90+ days
Insights never referenced for 90 days are archived. Insights with low use after 30 days are flagged.
Sleep 24h next run
Process stays alive in the curator tmux session, wakes up exactly 24 hours later.
