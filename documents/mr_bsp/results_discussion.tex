\section*{Interpretation and reproducibility}
Experiment 25's 30-seed single-session means must not be compared as though they were the same estimator as Experiment 27/28's seed-0 sequential terminal outcomes. The epsilon pilot does not establish a smooth entropy--communication trade-off; $\epsilon=0.3$ and $0.6$ have identical reported terminal metrics in this seed. Multiple paired seeds are needed.

Experiment 27 raw result files are in ANPLOS \path{mr_results/landmark_analysis}: the seed-0 Baseline-I, Baseline-II, and \path{terminalfixed_durable} JSON outputs dated 2026-09-16. Experiment 28 uses the corresponding seed-0, \path{samples3} JSON files dated 2026-09-17. The Experiment 28 recorded source state is commit \texttt{7d7c9b0} plus dirty/untracked source hashes, so the commit alone is insufficient for bit-for-bit reproduction. Experiment 29 should run independent $(\mathrm{seed},\mathrm{policy})$ cells at a fixed belief-sample count and preserve per-cell timing, progress, and results.
